# Allur: цифровой двойник завода

Backend API для кейса цифрового двойника. Хранит производственные показатели в SQLite, загружает демонстрационные данные из задания при первом запуске и считает KPI и предупреждения.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

По умолчанию база создаётся в `factory.db` в текущей папке. Чтобы указать другой путь, задайте переменную окружения `DATABASE_PATH`.

Документация и интерактивная проверка API доступны по адресу `/docs`, OpenAPI — `/openapi.json`.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/health` | Проверка доступности |
| GET, POST | `/api/lines` | Фактические показатели линий; фильтр `start_date`, `end_date` |
| GET, POST | `/api/downtimes` | Простои оборудования; фильтр по датам |
| GET, POST | `/api/quality` | Производство и брак по участкам; фильтр по датам |
| GET, POST | `/api/plans` | Месячный план по моделям |
| PUT, DELETE | `/api/plans/{plan_id}` | Изменить или удалить план модели |
| GET | `/api/dashboard` | KPI и предупреждения; фильтр по датам |
| GET | `/api/alerts` | Только предупреждения; фильтр по датам |
| GET | `/api/production-flow` | Последовательность производственных участков |

OEE вычисляется как приближённый показатель по полям из задания: средняя загрузка × выполнение плана × доля годной продукции. Данные задания не содержат нормативного времени цикла, поэтому классическая формула OEE недоступна. План 2 500 + 1 800 + 500 даёт 4 800 машин в месяц, поэтому API выдаёт предупреждение относительно целевого выпуска 5 500.

В POST-запросах даты передаются в ISO-формате (`YYYY-MM-DD`). Для простоя поле `is_critical` по умолчанию равно `true`; превышение 60 минут проверяется в сумме по критичному оборудованию за сутки.

## Демо-интерфейс

После запуска откройте `http://127.0.0.1:8000/`. На дашборде есть схема линии с состояниями участков, детализация участка по клику, рекомендации, график выпуска, месячный план и журнал событий. Кнопка «Симулировать смену» предлагает штатный сценарий, сбой камеры окраски или рост брака. «Сбросить демо» возвращает исходные данные.

Дополнительные маршруты: `GET /api/factory-state`, `GET /api/recommendations`, `GET /api/plan-recommendation`, `GET /api/events`, `POST /api/simulation/shift`, `POST /api/simulation/reset`. Подробный сценарий выступления для жюри — в [DEMO_SCRIPT.md](DEMO_SCRIPT.md).
